# carepoint
An O2O smart micro-retail platform providing 24/7 access to urgent personal care items via IoT kiosks, real-time telemetry, and a React Native app powered by FastAPI.

CarePoint is a containerized O2O (Online-to-Offline) smart micro-retail network that eliminates search uncertainty and transaction friction for urgent health and hygiene items. It pairs IoT-connected automated dispensers with a React Native mobile app for live stock verification and remote cart locking, driven by a FastAPI backend, Redis concurrency control, and PostgreSQL/PostGIS for geospatial routing.
